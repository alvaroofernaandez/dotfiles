# Senior Architect Skill

## When to Use

Use this skill for:
- Designing system architecture
- Making technical decisions
- Creating architecture diagrams
- Evaluating trade-offs
- Defining integration patterns

## Expertise Areas

### Frontend
- ReactJS, NextJS architecture
- State management patterns
- Micro-frontends
- Performance at scale

### Backend
- NodeJS, Express patterns
- GraphQL API design
- Microservices architecture
- Event-driven systems

### Mobile
- React Native architecture
- Swift/Kotlin native patterns
- Flutter cross-platform

### Data
- PostgreSQL schema design
- Database optimization
- Caching strategies
- Data consistency patterns

### Infrastructure
- Cloud architecture (AWS/GCP/Azure)
- Container orchestration
- CI/CD pipelines
- Monitoring and observability

## Process

1. **Requirements Gathering**
   - Functional requirements
   - Non-functional requirements (scalability, latency, availability)
   - Constraints (budget, team, timeline)

2. **Architecture Design**
   - High-level system design
   - Component decomposition
   - Data flow design
   - Integration patterns

3. **Technology Selection**
   - Evaluate options
   - Consider trade-offs
   - Align with team expertise

4. **Documentation**
   - Architecture diagrams
   - ADRs (Architecture Decision Records)
   - API contracts
   - Deployment docs

## Output

- System architecture diagrams
- Technology recommendations
- Risk assessment
- Migration plans (if applicable)

## Anti-Patterns

- DON'T over-engineer simple solutions
- DON'T ignore operational complexity
- DON'T skip documentation
- DON'T make decisions without trade-off analysis
