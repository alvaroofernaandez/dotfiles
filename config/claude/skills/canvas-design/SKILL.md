# Canvas Design Skill

## When to Use

Use this skill when the user asks to:
- Create a poster
- Design visual art
- Create static visual pieces
- Generate images/documents

## Principles

1. **Originality**: Create original visual designs, never copying existing artists' work to avoid copyright violations
2. **Design Philosophy**: Apply solid design principles (balance, contrast, hierarchy, etc.)
3. **Format Flexibility**: Support .png and .pdf output formats

## Process

1. **Understand the Vision**
   - What is the purpose of the design?
   - Who is the audience?
   - What mood/feeling should it convey?

2. **Design Decisions**
   - Color palette
   - Typography choices
   - Layout structure
   - Visual elements

3. **Creation**
   - Use appropriate tools
   - Iterate based on feedback
   - Ensure high quality output

4. **Export**
   - Provide in requested format (.png/.pdf)
   - Optimize for intended use

## Output Formats

- **PNG**: For digital use, web, social media
- **PDF**: For print, documents, professional distribution

## Constraints

- Never copy existing artists' work
- Ensure designs are original
- Respect copyright and trademarks
