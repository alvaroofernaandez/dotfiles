# Senior Frontend Skill

## When to Use

Use this skill for:
- Developing frontend features
- Optimizing performance
- Implementing UI/UX designs
- Managing state
- Reviewing frontend code

## Technology Stack

- **ReactJS**: Modern patterns, hooks, concurrent features
- **NextJS**: App Router, Server Components, optimization
- **TypeScript**: Strict mode, type safety, generics
- **Tailwind CSS**: Utility-first, responsive design, theming

## Capabilities

### Component Development
- Scaffolding components with proper structure
- Implementing accessible UI patterns
- Creating reusable component libraries

### Performance Optimization
- Code splitting and lazy loading
- Bundle analysis and optimization
- Rendering optimization
- Image and font optimization

### State Management
- Local state with hooks
- Global state (Zustand, Redux Toolkit)
- Server state (TanStack Query)
- URL state management

### Styling
- Tailwind CSS best practices
- CSS-in-JS when needed
- Responsive design patterns
- Dark mode implementation

## Process

1. **Understand Requirements**
   - UI/UX specifications
   - API contracts
   - Accessibility requirements
   - Browser support

2. **Implementation**
   - Write TypeScript first
   - Follow component patterns
   - Implement error boundaries
   - Add loading states

3. **Optimization**
   - Profile performance
   - Optimize re-renders
   - Lazy load where appropriate

4. **Testing**
   - Unit tests for logic
   - Component tests for UI
   - E2E tests for flows

## Anti-Patterns

- DON'T use `any` types
- DON'T ignore accessibility
- DON'T skip error handling
- DON'T over-engineer simple components
