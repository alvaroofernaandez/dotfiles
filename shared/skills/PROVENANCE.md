# Skill provenance

Attribution for every vendored skill that declares a licence. MIT and
Apache-2.0 both permit redistribution and both require the notice to travel
with the work, so this file exists to keep that obligation visible when the
skills are read through the symlink farm rather than in their own repos.

Each skill's own `SKILL.md` frontmatter carries the authoritative `license:`
and `author:` fields — never strip them. `tests/provenance.test.sh` fails if a
licensed skill is missing from the table below.

Skills with no licence line are this repo's own work, or are vendored under a
pin with its own provenance header (`gstack-sync.sh`, `p87-sync.sh`,
`uiux-sync.sh`).
